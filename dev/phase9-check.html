Phase 9 dry run — MeF readiness gap audit

This is not Phase 9 itself. Real Phase 9 (per IMPLEMENTATION_PLAN.md) is gated on an actual IRS/state MeF schema, which is not available yet. This harness runs the §25 "MeF Real-World Readiness Checklist" constructs — plus one extra construct found while building these fixtures — as synthetic XSD/XML test cases through the real flattener.js / parser.js / xmlReader.js / xmlWriter.js / validation.js modules, so each gap is demonstrated empirically rather than asserted from reading the source. Every GAP row below is an expected failure — it PASSES because it confirms the documented current behavior; if a future change to the parser fixes one of these, its row will start failing and needs updating (and the corresponding line in PHASE9_DRYRUN_FINDINGS.md resolved). A row that fails means actual behavior diverged from what this audit predicted and should be investigated before trusting the finding.
